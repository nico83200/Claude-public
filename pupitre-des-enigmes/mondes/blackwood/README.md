# Monde : Le Manoir Blackwood

Une enquête gothique dans un manoir de Dartmoor, la nuit du 31 octobre 1893 : Lord Edgar
Blackwood est mort dans sa bibliothèque, une heure avant minuit. La tempête, la lampe à
huile qu'il faut sans cesse remonter, une séance de spiritisme, un fantôme qui parle.
