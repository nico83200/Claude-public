# Monde : Le Manoir Harrington

Londres, novembre 1925, une nuit de brouillard. Lord Harrington gît inconscient dans son bureau, le
coffre est vide, et l'Œil de Jade a disparu. **Le Vol de l'Œil de Jade** est une enquête mêlée de
manipulations : les gemmes sur la loupe, la clé de dérivation, le cadran de la TSF.
