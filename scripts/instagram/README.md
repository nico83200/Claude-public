# Publications Instagram (10 visuels carrés 1080×1080)

1. `php fixtures.php` (base de développement, données de démonstration) puis application lancée sur http://127.0.0.1:8011
   avec le faux serveur Claude de `scripts/tutoriel` (prénom « Léo »).
2. `node capture.mjs <dossier>/cap` : captures téléphone (390×844, ×2,5).
3. Copier `public/icons/icon-192.png` et générer `qr.svg` (segno, vers https://jackcie.nlapps.fr/application-mobile).
4. `node render.mjs <dossier>` : un PNG par entrée de `posts.json` (thème clair/sombre, accroche, texte, capture, bulle ou notification).

Textes d'accompagnement : `dist/instagram/textes-publications.md`.
