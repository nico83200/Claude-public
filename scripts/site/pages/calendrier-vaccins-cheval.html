Vaccins du cheval : le calendrier à connaître

Grippe, tétanos, rhinopneumonie : quels vaccins, à quel rythme, et ce qu'exigent les compétitions. L'essentiel en cinq minutes, pour en parler sereinement avec votre vétérinaire.

Mis à jour le 14 octobre 2026 · 5 min de lecture

{{icon:alert}} Ce guide résume les pratiques courantes en France. Le protocole de votre cheval (âge, mode de vie, région, vaccins utilisés) est toujours décidé avec votre vétérinaire.

Le tétanos concerne tous les chevaux : la bactérie vit dans le sol, une simple plaie suffit. La grippe circule dès que les chevaux se croisent (concours, stages, pensions). La rhinopneumonie est exigée dans de nombreuses écuries et sur certaines manifestations, notamment d'élevage. D'autres vaccins (rage, gourme, West Nile…) se discutent au cas par cas avec le vétérinaire.

Et si vous sortez en compétition ?

Les vaccinations contre la grippe doivent être inscrites dans le document d'identification (le « carnet ») par le vétérinaire, avec la date et le nom du vaccin. Un retard de rappel peut obliger à recommencer toute la primovaccination.

  • Compétitions fédérales (FFE) : primovaccination complète, puis un rappel au moins annuel ;
  • Compétitions internationales (FEI) : rappel dans les 6 mois (avec une tolérance de 21 jours) ;
  • dans les deux cas, pas de vaccination dans les 7 jours qui précèdent l'arrivée sur le concours.

Ces règles évoluent : vérifiez toujours le règlement en vigueur de votre discipline avant la saison.

Un exemple de calendrier sur deux ans

Pour un cheval adulte jamais vacciné, en accord avec le vétérinaire :

  1. Mois 0 : grippe + tétanos (1re injection), rhinopneumonie (1re injection) ;
  2. Mois 1 : grippe + tétanos (2e), rhinopneumonie (2e) ;
  3. Mois 6–7 : rappel grippe, rappel rhinopneumonie ;
  4. Mois 12–13 : rappel grippe + tétanos, rappel rhinopneumonie ;
  5. ensuite : grippe chaque année (ou tous les 6 mois), rhinopneumonie tous les 6 mois, tétanos tous les 2 à 3 ans.

Les erreurs les plus fréquentes

  • Laisser passer la date d'un rappel : c'est la plus courante, et elle peut coûter une primovaccination complète.
  • Vacciner juste avant un concours : interdit dans les 7 jours, et un cheval peut être un peu fatigué après l'injection.
  • Oublier de faire signer le carnet : une vaccination non inscrite n'existe pas pour un contrôle.
  • Vacciner un cheval malade ou fiévreux : mieux vaut reporter, le vétérinaire en juge.
